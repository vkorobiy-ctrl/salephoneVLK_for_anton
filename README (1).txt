iPhone configurator — локальный демо-сайт
=========================================

Откройте index.html двойным кликом. Больше ничего делать не нужно.
Ни сервера, ни npm, ни сборки, ни интернета.

ВАЖНО: теперь все картинки вшиты прямо внутрь index.html (webp + base64).
Файл самодостаточный — можно скачать один index.html без папки assets,
и всё равно всё будет работать. Это же исправляет ситуацию, когда
картинки не видны при просмотре файла в чате.

Папка assets/ оставлена с исходными PNG — на случай, если вы захотите
их редактировать. Чтобы сайт брал картинки из файлов, а не из вшитых
данных, поменяйте в начале <script>:

    const USE_FILES = false;   ->   const USE_FILES = true;

Тогда пути будут ./assets/<key>.png, где key — это поле key у каждого
цвета в массиве PRODUCTS.

МОДЕЛЬНЫЙ РЯД
-------------
  iPhone 16 Pro       Black Titanium

  iPhone 17 Pro       Cosmic Orange, Deep Blue, Silver
  iPhone 18 Pro Max   Black, Sky, Purple, Red   <- её настраивает демо

Цвета кружков-свотчей взяты пипеткой из самих изображений.


ЧТО ПРОИСХОДИТ ПРИ ОТКРЫТИИ
---------------------------
Демо запускается само: iPhone 17 -> 17 Pro -> 18 Pro Max -> выбор модели ->
конфигуратор -> цвет -> память -> SIM -> Continue -> размер -> Continue ->
коробка -> телефон падает внутрь -> коробка закрывается -> конфетти ->
зелёная галочка. Около 10 секунд.

Любое касание или клик мгновенно останавливает автодемо — дальше интерфейс
полностью ваш. Работают стрелки клавиатуры и свайпы.
Кнопка «Watch again» на финальном экране запускает всё заново.

Кнопка Continue реагирует и на click, и на pointerup, и работает на любом
этапе (карусель -> конфигуратор -> размер -> упаковка). Блокировка во время
перехода между экранами теперь по таймеру, зависнуть навсегда не может.

Если вдруг скрипт где-то упадёт, внизу экрана появится красная плашка
с текстом ошибки — не будет «просто ничего не происходит».
